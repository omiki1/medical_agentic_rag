用户修改后的版本运行 39 条按模式展开的问答，自动检查通过 **34 / 39**。完整原始回答保存在 `reports/answer-quality-before-review.json`。这个数字不是医学正确率：逐条阅读后，部分自动通过的回答仍存在明显问题。

| 问题 | 实际发现 | 判断与处理 |
|---|---|---|
| 甲亢是什么 | 定义直接，能说明激素过多的含义 | 基础问答已明显改善，保留自然解释 |
| 睡眠问题的原因 | 正常原因后继续罗列哮喘、沙蚤病等 | 有引用仍可能偏离用户需要；提高题名/实体主题权重，限制无关扩写 |
| 糖尿病吃饭注意什么 | 大量泛谈“健康饮食”，甚至转去介绍药物 | 缺少实际饮食内容，自动关键词检查过宽；补入 NIDDK 饮食资料，强化食物/份量检查 |
| 糖尿病可以吃水果吗 | 检索资料只说健康饮食，生成失败后展示英文摘录 | 存在真正的资料缺口；补入有直接支持的官方资料 |
| 胃胀、打嗝是不是胃癌 | 生成失败后回退到含“酸碱体质治癌”的历史原文 | 严重的质量出口缺陷；禁止以摘录绕过失败的生成检查，过滤明显伪医学宣称 |
| 老人骨质疏松预防 | 根据旧文建议长期雌激素替代和固定检查频次 | 不能把历史建议直接推广给当前用户；加入 NHS 生活方式资料，强化治疗建议审阅 |
| 普通头晕 | 罗列血虚、肝火和缺少白色甲半月等不可靠描述 | 答复没有合理分层；改进主题排序，并补入头晕官方说明 |
| 哮喘发作怎么办 | 讲吸入剂及自制间隔装置，缺少清晰求助边界 | 强化个人行动计划和恶化时求助，不把一种吸入器方案套给所有人 |
| 高血压预防 | 将“2 克”直接写成每日食盐上限 | 来源页面本身有钠/盐措辞歧义；过滤该歧义片段，使用 WHO 专门的减钠资料 |

高血压页面的中英文版本都含有容易混淆的“2 克”措辞。WHO 的[减钠专题](https://www.who.int/news-room/fact-sheets/detail/sodium-reduction)明确区分成人每日少于 2 克钠与约 5 克食盐，说明“来自权威网站”仍不等于每个转述都正确。

## 已落地的工程修正

- 保留宽泛问题可使用原因、预防、症状等多分面的设计；题名/实体命中优先于正文偶然提及。
- 修正同主题候选按相关度升序的错误，最终重排后重新分配 rank 与 E 编号。
- 补充甲减的规范名称匹配、诊断检查问法、口语剂量问法、突发剧烈头痛和 FAST 类描述；保留否定句检查。
- 明确允许 LLM 自然概括、术语解释、逻辑衔接及审慎的背景追问，不要求解释与原文逐字一致。
- 生成或语义审阅失败时，不再自动输出历史原文。来源仍可查看，界面明确显示“解释未完成”。
- 历史文档中的明确酸碱体质治癌等宣称不作为候选；未删除或改写原始 legacy 数据。
- 本轮补入 8 条官方中文整理摘要，与此前 7 条合计 15 条，源文件和来源链接可审阅。该补充是对已发现覆盖缺口的修复，不代表整个知识库已完成医学审核。
- 新摘要的别名仅用于同义名称，不把水果、胃胀、打嗝等食物或症状映射为疾病诊断。

## 测试设计与边界

`evaluation/comprehensive_cases.json` 包含 52 条按模式展开的问答：39 条既有场景，加上口语化症状、连续追问、否定急症、甲亢/甲减比较、剂量、提示注入和非医学问题。偏头痛在新增 NHS 症状资料后，权威模式预期由缺证据调整为有证据；变更原因写在用例中，首轮旧报告保留。

检查项包含路由、主题、具体回答内容、错误片段、篇幅、生成模式、引用校验和 QA 排除。新增边界场景也检查提示是否有用，不能只凭拒答状态判通过。完整回答、分析结果、证据来源、相关度、修复原因、耗时和模型调用数保存在报告中；代码与用例均记录 SHA-256。

`previous_question` 测试验证 Agent 的追问解释；账户隔离、持久化与 SSE 生命周期由独立集成测试覆盖，不将一次追问测试宣称为全部记忆系统端到端验证。

## 核对使用的官方页面

- [NIDDK 糖尿病健康生活与饮食](https://www.niddk.nih.gov/health-information/diabetes/overview/healthy-living-with-diabetes)：饮食计划可包括水果，并考虑份量、碳水化合物和个人安排。
- [NHS 头晕](https://www.nhs.uk/symptoms/dizziness/)与[偏头痛](https://www.nhs.uk/conditions/migraine/)：可能原因、常见表现及求助边界。
- [NHS 胃癌症状](https://www.nhs.uk/conditions/stomach-cancer/symptoms/)：消化道症状缺乏特异性，不能凭症状确诊。
- [NHS 骨质疏松预防](https://www.nhs.uk/conditions/osteoporosis/prevention/)与[哮喘](https://www.nhs.uk/conditions/asthma/)：一般预防措施、个人行动计划及求助。
- [NHS 卒中症状](https://www.nhs.uk/conditions/stroke/symptoms/)与[头痛](https://www.nhs.uk/symptoms/headaches/)：用于核对新增急症表达。
